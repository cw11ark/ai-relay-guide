⚠️ 点击本文任何官网链接之前，先读这五条
  1. 数据隐私：中转站能看到你的全部请求内容。各家数据保存/日志政策未经核验 ⇒ 无论条款写了什么，密钥、客户数据、保密代码一律不要经过中转渠道，先用脱敏样本试。
  2. 模型身份未证实：本文所有"模型校验"只做到"响应 model 字段与请求一致/不一致"的观察。中转方技术上可以改写字段 ⇒ 字段一致 ≠ 底层是原版模型；正文型号一律按"渠道标称型号"理解。
  3. 隐藏提示词注入：AgentRouter 部分链路观察到附加兼容性指令，会改变应用原本的指令边界。对系统提示词敏感的工具（编程 Agent、JSON 结构化输出）可能受干扰——接入前先小流量验证。
  4. 失败与计费：429 = 被限流（重试要退避 + 上限，连发放大拥堵）；500/超时重试前先确认是否已扣费、任务是否幂等（重复执行可能重复扣费或重复副作用）。
  5. 预扣费：AgentRouter 观察到百万 token 级单发会按上限预扣约 $36（平台账面额度口径，释放规则因时而异）⇒ 大文档先小额分片试探，分片降低单次预扣但不保证总成本更低。

开始前，先回答三个问题

  1. 你真的需要 API 中转吗？ 中转站卖的是 API 额度，不是聊天会员——需要配客户端（Cherry Studio / ChatBox / Claude Code 等）或自己写代码调用。
  2. 你跑什么任务？ 短问答、写代码、长文档分析，成本结构完全不同——按任务算完账再看。
  3. 哪些渠道？ 看下面按任务导航，不要看总榜。

计费方式与算账方法

两个术语一句话：

  • Token：模型计量文本的单位，1 个汉字 ≈ 1~2 token，token 数 ≠ 字数。
  • 按量 vs 按次：按量 = 按 token 量计费（¥/百万 tokens，输入输出分开）；按次 = 每次请求固定费用。两种方式没有普适的谁更省——取决于每次请求的 token 量、上限和成功率。

算账方法（示例，数字为假设）：

假设输入 ¥1/M、输出 ¥2/M，每次请求 1 万输入 + 2 千输出 token：
按量成本 = (10000/10⁶)×¥1 + (2000/10⁶)×¥2 = ¥0.014 / 次

若某按次站报价 ¥0.0002/次（同模型、不超限）：
此负载下按次约为按量的 1/70。

分界点思路：按量站的等效单次成本 = 输入token×输入单价 + 输出token×输出单价；算出你这个负载的等效单次成本，再和按次报价比，谁低用谁。

⚠️ 以上全部是假设数字的算术演示，不是任何一家站的实际比价结论。另外按次站通常有上下文/输出上限（如 42K），超限的任务按次再便宜也用不了。

小额试用步骤（第一次接入）

  1. 注册：走官网注册（AgentRouter 可 GitHub 登录 + 签到领额度，0 元起步）。
  2. 最小充值：先充最低档（5~10 元量级），跑通再放量。
  3. 发一条测试请求：短问题，看响应 model 字段、扣额是否合理。
  4. 对账：核对扣费与报价是否一致、失败请求是否被扣费。
  5. 小流量跑任务：先跑不重要的任务验证质量，再决定是否当主力。

⚠️ 试用期间密钥与敏感数据一律不过中转渠道（见开头风险 1）。
